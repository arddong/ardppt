# Glow PPT

행사 현장 발표 화면 송출 프로그램 (윈도우). 무료.

PPT·PDF·그림·영상을 묶음으로 올려 두고, 장을 눌러 TAKE 하면 두 번째 화면(LED·프로젝터)으로 나갑니다.

- 받기: [Releases](https://github.com/arddong/glow-ppt/releases/latest) → `GlowPPT_Setup_v1.0.exe`
- 버그 신고 · 기능 요청: https://chal-na.notion.site/2550a4124c6843fcb1086c9edb7d75f3

## 할 수 있는 것

- 왼쪽 = 자료 묶음(1번 운영 화면, 2번부터 발표 PPT) · 오른쪽 = 고른 묶음의 장들 · STANDBY → TAKE
- vMix 처럼 화면 맞춤 = 출력 크기(FHD · LED 2:1 · 3:1 · 32:9 · 4:3 · 직접 입력) · 크롭 / 늘림 / 여백 · 전체 또는 장마다
- 비율이 다른 장은 늘림을 막아 글자가 늘어나지 않음 · 여백 없이 꽉 채우기도 가능
- 영상 = 30초 이하는 반복(배경 · 태극기), 더 길면 한 번 재생 후 끝 장면 정지(홍보 영상) · 소리 크기 자동 맞춤
- 앱이 죽으면 3초 안에 다시 켜짐

## 설치

설치 파일을 받아 실행합니다. 관리자 권한이 필요 없고, 파이썬 · PPT 변환기(LibreOffice) · 영상 도구(ffmpeg)가 함께 들어 있어 따로 설치할 것이 없습니다.
서명되지 않은 프로그램이라 윈도우가 경고하면 「추가 정보 → 실행」을 누릅니다.

## 알아 둘 것

- PPT 의 애니메이션 · 화면 전환 효과는 정지 그림이 됩니다(PPT 속 영상은 따로 재생).
- 처음 넣은 영상은 소리 크기를 맞춘 사본을 먼저 만듭니다(4K 40초 약 18초). 그동안 「준비 중 N%」가 뜹니다.

이 저장소에는 설치 파일과 소개만 있습니다.
